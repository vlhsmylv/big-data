    5
    The whole course in one picture. Imagine a library with so many books that no single building can hold them. You spread the books over many small buildings (that is HDFS, the storage). When you want to count something in all the books, you send a worker to each building to count locally, then add up the results (that is MapReduce, the processing). Someone has to hand out workers and rooms so jobs don't fight (that is YARN, the manager). Together, these three are Hadoop.
